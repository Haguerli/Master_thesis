# Master_thesis
Code from my Master_thesis in the area of PAC and ToF_SIMS. Minimally commented. 
In the Anisotropie_coefficient and Asymetrie session,
the detector anisotropie and the eta parameter are calculated. 
Everything regarding Pac Spectra of self-written code is in Spectra_evaluation_with_Fourier. 
The ToF_Sims_data_analysis folder contains (inefficient) scripts for the analysis of the data from ToF-SIMS. It is mainly based on pySPM. Big Kudos to them!
